# JavaScript Mastery Map

## Mastery Scale Reference

| Score | Level Name | Criteria |
|---|---|---|
| **0** | **Not Introduced** | Topic has not been taught or tested yet. |
| **1** | **Recognition** | Recognizes the concept/syntax but cannot explain or implement it independently. |
| **2** | **Guided Understanding** | Understands with explanations, documentation prompts, or hints. |
| **3** | **Independent Competence** | Can independently implement a solution to a new problem and explain how/why it works. |
| **4** | **Deep Mastery** | Can apply, debug, optimize, handle edge cases, and transfer knowledge to unfamiliar problems. |
