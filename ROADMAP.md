# JavaScript Mastery — Curriculum Roadmap

Advancement across this roadmap depends strictly on **demonstrated mastery (Level 3+)**, not speed. Vanilla JavaScript fundamentals must be rock-solid before touching Node.js or any framework.

---

## LEVEL 0 — ZERO PROGRAMMING KNOWLEDGE (Current Level)
### Core Concepts
- What is programming?
- What is JavaScript?
- How does a program execute?
- Instructions and statements
- Console (`console.log`, inspecting output)
- Basic syntax & punctuation
- Comments (`//` and `/* */`)
- Strings (text data)
- Numbers & basic arithmetic (`+`, `-`, `*`, `/`, `%`, `**`)

### Foundational Exercises
- Predict simple program outputs (Code Tracing)
- Identify valid and invalid instructions (Syntax Diagnostics)
- Create basic output instructions
- Explain simple programs in plain English / Taglish
