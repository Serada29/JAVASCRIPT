# Mentor Skills Directory

This directory houses the detailed skill definitions for the slash commands listed in [`SKILLS.md`](../SKILLS.md).

## On-Demand Generation Rule
Per our mentorship rules (Section 17):
- Initially, only the catalog in [`SKILLS.md`](../SKILLS.md) is created.
- Detailed skill files are **not** pre-generated here until you explicitly invoke `/build-skill <name>`.
- When you run `/build-skill <name>`, a dedicated `<name>.md` specification will be created in this directory.
