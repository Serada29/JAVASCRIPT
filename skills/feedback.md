# Skill: `/feedback`

## Overview
Evaluates your in-progress code or answers, diagnoses bugs and thinking gaps without writing solutions for you, provides progressive hints, and introduces one useful new JavaScript concept/method tailored to the exact problem you're solving.

## Trigger
- `/feedback`

## Procedures
1. Inspect active code/answers and run the script in Node.js to observe real output.
2. Highlight what works, diagnose what is wrong, and update `MISCONCEPTIONS.md` if needed.
3. Explain the senior-engineering mental model needed to approach the problem.
4. Provide targeted hints (no complete solutions).
5. Deliver a **Contextual Micro-Lesson**: teach 1 new JavaScript method/concept (e.g., `.find()`, `.forEach()`, `.filter()`, object references) with an unrelated tiny example and MDN link.
