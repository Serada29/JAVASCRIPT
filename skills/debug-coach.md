# Skill: `/debug-coach`

## Overview
Coaches the user through debugging runtime or syntax errors systematically using the 5-step debugging protocol without giving away the fix.

## Trigger
- `/debug-coach`
- `/explain-error`

## Procedures
1. Ask the 5 Core Debugging Questions (Expected vs. Actual, Error Name, File/Line, Root cause hypothesis).
2. Apply the Struggle-First Hint System (Hint 0 to 4).
3. Verify that the user applies the fix themselves and re-runs the code in Node.js.
