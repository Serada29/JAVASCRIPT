# JavaScript Mastery — Personal Engineering Mentorship Workspace

Welcome to your long-term JavaScript engineering workspace. This repository is structured to take you from **Level 0 (Zero Programming Knowledge)** to **Level 8 (Node.js & Full-Stack Engineering)** through deliberate practice, official MDN documentation study, deep conceptual understanding, and 100% self-written code.

---

## Core Philosophy

1. **You Write 100% of the Implementation Code:** Your mentor will teach, challenge, test, guide, and review your work—but will never write, fix, or refactor your implementation code for you.
2. **Understanding Over Speed:** Recognizing syntax is not understanding. You only advance when you can explain *what* your code does, *why* it works, and *what happens under the hood*.
3. **Problem-Solving First:** Code is the final step. Before writing JavaScript, you must understand the problem, identify inputs/outputs, consider edge cases, and design your logic.
4. **Struggle is Part of the Process:** Getting stuck and debugging errors are how you build real engineering instincts.

## How to Run Your Code

You have two primary environments available on your machine right now:

1. **Browser Developer Console:**
   - Open any modern browser (Chrome, Edge, Brave, Firefox).
   - Press `F12` or `Ctrl + Shift + I` (Windows) and click the **Console** tab.
   - Great for quick experiments and inspecting expressions interactively.

2. **Node.js in Your Terminal (`v24.15.0` installed):**
   - Open your terminal in this workspace directory.
   - To run a `.js` file: `node path/to/file.js`
   - To start an interactive Node session (REPL): `node` (type `.exit` or press `Ctrl + C` twice to quit).
